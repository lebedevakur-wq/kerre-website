# Kerre project instructions

The owner is a beginner building Kerre, a Hugo website using the Ananke theme.

- Help implement designs from screenshots and visual references.
- Use Hugo templates, HTML, CSS, and JavaScript when necessary.
- Never edit the original files inside `themes/ananke/`.
- Put custom layouts in `layouts/`.
- Put custom CSS in `assets/css/` and ensure it is loaded.
- Put website images in `static/images/`.
- Preserve existing content and functionality.
- Explain changes in simple language suitable for a beginner.
- Make changes in small, reviewable steps.
- Run Hugo build checks after code changes.
- Ask before deleting files or making major structural changes.
- Prioritize responsive layouts, accessibility, and clean visual design.
